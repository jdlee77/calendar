Outlook import and export

How to get a calendar file out of Outlook
Outlook for Windows (classic)
Open your calendar, then choose File › Save Calendar. Select More Options, set Date Range to Whole calendar and Detail to Full details, then save. This makes an .ics file.
New Outlook for Windows and Outlook on the web
Go to Settings › Calendar › Shared calendars. Under Publish a calendar, pick your calendar and "Can view all details", then Publish. Open the ICS link it gives you in a browser to download the .ics file. Some workplaces turn publishing off.
Outlook for Mac
Use Outlook on the web (steps above), or drag events from the calendar to your desktop to make .ics files.
Spreadsheet (.csv) from Outlook for Windows (classic)
File › Open & Export › Import/Export › Export to a file › Comma Separated Values, then choose your Calendar folder and a date range.

How to add the file to Outlook
New Outlook and Outlook on the web
Open Calendar, choose Add calendar › Upload from file, pick the .ics file, choose which calendar to add it to, then Import.
Outlook for Windows (classic)
File › Open & Export › Import/Export › Import an iCalendar (.ics) or vCalendar file. Pick the file, then choose Import to add the events to your calendar. For a .csv, choose Import from another program or file › Comma Separated Values and select your Calendar folder.
Outlook for Mac
Double-click the .ics file, or drag it onto the calendar.
